# Figures

Figures extracted from the Master's thesis *Sistema multisensorial para la
interacción física humano-robot* (R. Castro Ochoa, Universidad de Málaga, 2026),
included here to illustrate the method.

| File | Source | Shows |
|------|--------|-------|
| `fig2.7_forearm_ellipse_fit.png` | thesis fig. 2.7 (adapted from ref. [4]) | forearm cross-section modelled as an ellipse, 6 subjects |
| `fig3.1_visuotactile_block_diagram.png` | thesis fig. 3.1 | full visuo-tactile system block diagram |
| `fig3.5_contact_polygon.png` | thesis fig. 3.5 | gripper kinematic points, contact polygon, inscribed ellipse |
| `fig3.6_forearm_axis_reconstruction.png` | thesis fig. 3.6 | forearm axis, elbow and wrist from the two ellipse centres |
| `fig3.7_arm_frame_vs_major_diagonal.png` | thesis fig. 3.7 | `{arm}` frame and the distal ellipse major diagonal used for q5 |
| `fig4.11_gripper_topview_pron_sup.png` | thesis fig. 4.11 | Experiment 2 setup: both pinches + hand-held accelerometer, pronation/supination |
| `fig4.15_q5_continuous_tracking.png` | thesis fig. 4.15 | Experiment 3: continuous tactile q5 vs. accelerometer ground truth |
